Claude Fable 5.2 是什麼？

Claude Fable 5.2 是 Anthropic 在 2026-11-09 發布的 AI 模型。發布幾天內，大家就用它靠提示詞做出了完整的網頁遊戲、3D 世界、工具和用程式碼驅動的短片。Fable List 收錄這些作品，目前有 258 個可打開的作品和 157 個影片展示，來自 260 位作者。

大家用 Claude Fable 5.2 做了什麼？

按分類：遊戲 123、3D 世界與場景 56、網頁與工具 60、動畫與短片 19、影片展示 157。按讚最多的是 @claudeai 的 Anthropic：發表前的專案，X 上 43,051 讚。

用 Claude Fable 5.2 做一個作品要花多少錢？

差別很大。按作者自己在貼文裡說的：一句提示詞做出的火箭遊戲 Go for Launch 用了 1 小時 18 分鐘、約 $30 的 API token；過夜建置的 Rome, AD 320 估算花了 $2,618。多數作品的生成時間從幾分鐘到好幾個小時不等。
