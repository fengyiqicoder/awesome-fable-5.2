Claude Fable 5.2란 무엇인가요?

Claude Fable 5.2는 Anthropic이 2026-11-09에 출시한 AI 모델입니다. 출시 며칠 만에 사람들은 프롬프트로 완성된 브라우저 게임, 3D 월드, 도구, 코드로 만든 영상을 만들었습니다. Fable List는 이를 모아 두며, 현재 180명의 제작자가 만든 작품 156개와 영상 데모 112개가 있습니다.

Claude Fable 5.2로 무엇을 만들었나요?

분류별: 게임 80, 3D 월드와 장면 33, 웹 페이지와 도구 32, 애니메이션과 영상 11, 영상 데모 112. 가장 많은 좋아요를 받은 것은 @claudeai의 Anthropic: 출시 전 프로젝트(X 좋아요 43,051개)입니다.

Claude Fable 5.2로 작품을 만드는 데 비용이 얼마나 드나요?

편차가 큽니다. 제작자 본인의 게시물에 따르면 프롬프트 하나로 만든 로켓 게임 Go for Launch는 1시간 18분, API 토큰 약 $30, 밤새 빌드한 Rome, AD 320는 약 $2,618이 들었습니다. 대부분 몇 분에서 몇 시간이 걸립니다.

이 작품들의 프롬프트는 어디서 볼 수 있나요?

38명의 제작자는 자신의 프롬프트를 공개했으며, 해당 카드에서 무료로 바로 볼 수 있습니다. 나머지 작품은 Fable List가 코드나 영상을 보고 210개의 프롬프트를 재구성해 하나의 Claude Skill로 묶었습니다. ✨ 프롬프트 →
