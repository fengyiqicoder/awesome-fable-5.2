Claude Fable 5.2 の作品についてよくある質問

Claude Fable 5.2 とは？

Claude Fable 5.2 は Anthropic が 2026-11-09 にリリースした AI モデルです。数日のうちに、プロンプトから完全なブラウザゲーム、3D ワールド、ツール、コードで動く映像が作られました。Fable List はそれらを集めており、現在 180 人の作者による 156 件の作品と 112 件の動画デモがあります。

Claude Fable 5.2 で何が作られている？

分類別：ゲーム 80、3D ワールドとシーン 33、Web ページとツール 32、アニメーションと映像 11、動画デモ 112。最も「いいね」が多いのは @claudeai の Anthropic：リリース前のプロジェクト（X で 43,051 いいね）。

Claude Fable 5.2 で作品を作るといくらかかる？

大きく異なります。作者本人の投稿によると、1 つのプロンプトで作ったロケットゲーム Go for Launch は 1 時間 18 分・約 $30 の API トークン、一晩かけた Rome, AD 320 は推定 $2,618 でした。多くは数分から数時間かかります。

これらの作品のプロンプトはどこで見られる？

38 人の作者は自分のプロンプトを公開しており、そのカードから無料で直接見られます。それ以外の作品については、Fable List がコードや動画から 210 本のプロンプトを再構成し、1 つの Claude Skill にまとめました。 ✨ プロンプト →

リストはどう確認・更新されている？

すべてのリンクは追加前に実際に開いて確認しています。12 時間ごとに新しい作品を追加し、X のいいね数を更新します。誰でも GitHub から作品を投稿できます。
